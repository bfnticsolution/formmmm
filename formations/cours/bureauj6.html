Module 1 20 minutes

1.1 Qu'est-ce que PowerPoint ?

Microsoft PowerPoint est un logiciel de présentation. Il permet de créer des diaporamas composés de diapositives (slides) projetées sur un écran. Il fait partie de la suite Microsoft Office, avec Word et Excel.

À quoi sert PowerPoint ?

  • Soutenir un discours lors d'une réunion.
  • Présenter un projet à des clients ou des partenaires.
  • Former des collaborateurs (comme ce cours !).
  • Pitcher une idée, un produit, une entreprise.
  • Animer un événement (mariage, conférence).

Principe fondamental

PowerPoint est un support, pas un document. Les diapositives ne sont pas faites pour être lues, mais pour illustrer votre discours. Peu de texte, beaucoup de visuels. Vous êtes le message principal, pas les slides.

Module 2 30 minutes

2.1 Créer des diapositives

Une présentation PowerPoint est constituée de diapositives (slides). Chaque diapositive peut contenir du texte, des images, des tableaux, des graphiques, des vidéos.

Ajouter et gérer des diapositives

Nouvelle diapoAccueil → Nouvelle diapositive (Ctrl+M).
SupprimerClic droit sur la miniature → Supprimer la diapositive.
DupliquerClic droit → Dupliquer la diapositive. Très utile pour garder la même mise en page.
RéorganiserGlissez-déposez les miniatures dans le volet de gauche.

Les dispositions (layouts)

Chaque diapositive a une disposition prédéfinie qui détermine l'emplacement des zones de texte et de contenu.

  • Diapositive de titre : pour la page d'accueil.
  • Titre et contenu : la plus utilisée.
  • Deux contenus : pour comparer.
  • Image avec légende : pour les visuels.
  • Vide : pour une liberté totale.
Astuce : Tapez directement dans les zones de texte existantes (« Cliquez pour ajouter un titre »). Ne créez pas de nouvelles zones de texte manuellement sauf nécessité absolue. Les dispositions assurent la cohérence.

2.2 Appliquer un design professionnel

Le design d'une présentation est crucial. Une présentation bien conçue renforce votre crédibilité. PowerPoint propose des thèmes prêts à l'emploi, entièrement personnalisables.

Les thèmes (onglet Création)

  1. Onglet Création.
  2. Parcourez la galerie de thèmes.
  3. Cliquez sur un thème pour l'appliquer à toute la présentation.

Un thème définit : les polices, les couleurs, l'arrière-plan, la position des éléments. Tout est cohérent automatiquement.

Personnaliser un thème

Vous pouvez modifier un thème après l'avoir appliqué :

  • Variantes : à droite de la galerie, changez les couleurs.
  • Polices : Création → Polices → Personnaliser.
  • Arrière-plan : Création → Arrière-plan → Style d'arrière-plan.
Les 5 règles d'or du design PowerPoint :
1. Moins c'est plus : maximum 6 lignes par diapo, 6 mots par ligne.
2. Contraste : texte foncé sur fond clair, ou clair sur fond foncé.
3. Cohérence : mêmes polices, mêmes couleurs sur toutes les diapos.
4. Visuels : une image vaut mille mots. Remplacez le texte par des images.
5. Police lisible : minimum 24 pt pour le corps, 36 pt pour les titres.

2.3 Insérer des éléments visuels

Une présentation percutante repose sur des visuels forts. PowerPoint permet d'insérer facilement des images, des formes, des icônes et des vidéos.

Images

Insertion → Images → Cet appareil. Ou faites glisser une image depuis l'Explorateur directement sur la diapositive.

Formes

Insertion → Formes. Rectangles, cercles, flèches, bulles... Idéal pour créer des schémas et des diagrammes.

Icônes

Insertion → Icônes. Des milliers d'icônes gratuites et libres de droits pour illustrer vos propos.

Conseil : Utilisez la fonction Insertion → SmartArt pour créer des diagrammes professionnels (organigrammes, processus, cycles) en quelques clics, sans rien dessiner.

Module 3 25 minutes

3.1 Les transitions entre diapositives

Une transition est l'effet visuel qui se produit lorsqu'on passe d'une diapositive à la suivante. Elle donne du rythme à votre présentation. Tous les réglages sont dans l'onglet Transitions.

Appliquer une transition

  1. Sélectionnez une diapositive (ou plusieurs avec Ctrl+clic).
  2. Onglet Transitions.
  3. Choisissez un effet dans la galerie.

La transition s'applique à l'arrivée de la diapositive sélectionnée. La première diapositive n'a pas de transition (sauf si vous le souhaitez).

Paramétrer une transition

Options d'effetChanger la direction (gauche, droite, haut...).
DuréeTemps de l'effet (1 à 2 secondes maximum).
SonAjouter un son à la transition (à utiliser avec parcimonie).
Passer à la diapositive suivanteManuellement (clic) ou automatiquement après X secondes.
Attention : Choisissez une ou deux transitions pour toute la présentation et appliquez-les partout. Varier les effets à chaque diapositive donne un résultat amateur. La simplicité est la clé du professionnalisme.

Module 3

3.2 Les animations d'objets

Une animation contrôle l'apparition, le déplacement ou la disparition d'un élément à l'intérieur d'une diapositive (texte, image, forme). Les animations sont gérées dans l'onglet Animations.

Types d'animations

OuvertureL'élément apparaît (entrée).
EmphaseL'élément attire l'attention (tourne, grandit...).
FermetureL'élément disparaît (sortie).
TrajectoiresL'élément suit un chemin dessiné.

Le volet Animation

Pour un contrôle précis, ouvrez le volet Animation (bouton dans l'onglet Animations).

  • Il liste toutes les animations de la diapositive.
  • Vous pouvez les réorganiser par glisser-déposer.
  • Choisir le déclencheur : au clic, avec la précédente, après la précédente.
  • Régler la durée et le délai de chaque animation.
Règle d'or des animations : Utilisez les animations pour faire apparaître les points un par un (pour que le public lise ce que vous dites, pas ce qui va suivre). Évitez les animations « fantaisistes » (tournoyer, rebondir, machine à écrire) en contexte professionnel.

Module 4 20 minutes

4.1 Le mode Diaporama

Le mode Diaporama est le mode de projection. Il affiche vos diapositives en plein écran, sans le Ruban ni les outils d'édition. C'est ce que voit votre public.

Lancer le diaporama

Depuis le débutF5. Lance à partir de la première diapositive.
Depuis la diapo actuelleShift+F5. Lance à partir de la diapositive sélectionnée.
Bouton DiaporamaEn bas à droite de la fenêtre PowerPoint.

Naviguer pendant la présentation

Espace, Entrée, →, ↓Diapositive suivante.
←, ↑Diapositive précédente.
N° + EntréeAller directement à la diapo N°.
B ou .Écran noir (ou blanc).
ÉchapQuitter le diaporama.

Module 4

4.2 Le mode Présentateur

Le mode Présentateur est une fonction avancée qui affiche des informations différentes sur votre écran et sur celui du public. Il nécessite deux écrans (votre PC + un projecteur ou un second écran).

Écran du public

Diapositive en plein écran

Votre écran

Diapositive en cours
+ Diapositive suivante
+ Vos notes
+ Chronomètre
+ Outils (laser, zoom)

Activer le mode Présentateur

  1. Branchez le second écran/projecteur.
  2. Onglet Diaporama.
  3. Cochez Mode Présentateur.
  4. Lancez le diaporama (F5).

Avantages du mode Présentateur

  • Voir vos notes sans que le public les voie.
  • Voir la diapositive suivante pour anticiper.
  • Voir le temps écoulé pour gérer votre timing.
  • Utiliser le pointeur laser ou le zoom sur un détail.
Exercice : Créez une présentation de 5 diapositives. Ajoutez des notes dans le volet Notes pour chaque diapositive. Lancez le mode Présentateur (même sans second écran, vous verrez l'aperçu).

Récapitulatif du Jour 6

Les 10 points clés à retenir

  1. PowerPoint est un outil de présentation, pas un traitement de texte.
  2. Une diapositive est un support visuel, pas un document à lire.
  3. Utilisez les dispositions existantes pour garantir la cohérence.
  4. Appliquez un thème (onglet Création) pour un design professionnel instantané.
  5. Règle du 6×6 : maximum 6 lignes par diapo, 6 mots par ligne.
  1. Une transition = passage entre deux diapos. Restez sobre.
  2. Une animation = mouvement d'un élément dans la diapositive.
  3. Utilisez les animations pour faire apparaître les points un par un.
  4. F5 = lancer le diaporama. Shift+F5 = depuis la diapo actuelle.
  5. Le mode Présentateur affiche vos notes et la diapo suivante.

Félicitations pour cette sixième journée !

Vous savez créer des présentations professionnelles avec PowerPoint.
