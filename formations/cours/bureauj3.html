Module 1 15 minutes

1.1 Le correcteur orthographique et grammatical

Word intègre un correcteur automatique qui vérifie l'orthographe, la grammaire et même le style de votre texte. C'est un outil indispensable pour produire des documents sans fautes.

Comment Word signale les erreurs

Souligné rougeFaute d'orthographe. Mot inconnu du dictionnaire Word.
Double souligné bleuFaute de grammaire. Accord, conjugaison, syntaxe.
Souligné pointilléProblème de style. Répétition, formulation maladroite.

Clic droit sur un mot souligné : Word propose des corrections. Cliquez sur la bonne pour l'appliquer.

Le vérificateur complet

Pour une relecture complète de votre document :

  1. Onglet Révision.
  2. Cliquez sur Orthographe et grammaire (ou F7).
  3. Word parcourt chaque erreur une par une.
  4. Pour chaque erreur, vous pouvez : Ignorer, Modifier ou Ajouter au dictionnaire.

La vérification s'arrête quand tout le document est relu.

Limite du correcteur : Word ne détecte pas les homophones (ex: « mer » et « maire »). Relisez toujours votre document vous-même après la correction automatique. Le correcteur est une aide, pas une garantie absolue.

Module 1

1.2 Les synonymes et la langue

Au-delà de la correction, Word propose des outils pour enrichir votre vocabulaire et travailler dans plusieurs langues.

Dictionnaire des synonymes

Vous répétez trop souvent le même mot ? Word peut vous proposer des synonymes.

  1. Sélectionnez le mot (ou clic droit dessus).
  2. Cliquez sur Synonymes.
  3. Choisissez le synonyme qui convient.

Raccourci : Shift+F7 ouvre le dictionnaire des synonymes.

Changer la langue

Si vous rédigez un document en anglais ou dans une autre langue :

  1. Sélectionnez le texte concerné.
  2. Barre d'état (en bas) : cliquez sur la langue actuelle.
  3. Choisissez la nouvelle langue.

Le correcteur s'adaptera automatiquement à la langue choisie.

Astuce : Si un mot correct (nom propre, terme technique) est souligné en rouge, faites clic droit → Ajouter au dictionnaire. Word ne le soulignera plus jamais.

Module 2 20 minutes

2.1 Qu'est-ce qu'un style ?

Un style est un ensemble de mises en forme (police, taille, couleur, alignement, interligne) enregistré sous un nom. Au lieu de formater chaque titre manuellement, vous appliquez un style en un seul clic.

Avantages des styles

  • Gain de temps : un clic au lieu de cinq.
  • Cohérence : tous les titres de même niveau sont identiques.
  • Modification globale : changez le style, tout le document se met à jour.
  • Table des matières automatique : indispensable pour le sommaire.
  • Navigation : le volet de navigation affiche la structure.

La galerie de styles

Dans l'onglet Accueil, groupe Styles, vous voyez une galerie de styles prêts à l'emploi :

NormalStyle de base pour le corps du texte.
Titre 1Pour les titres principaux (chapitres).
Titre 2Pour les sous-titres.
Titre 3Pour les sous-sous-titres.
CitationPour les citations en retrait.
À retenir : Utilisez Titre 1 pour les titres de chapitre, Titre 2 pour les sections, Titre 3 pour les sous-sections. C'est la clé pour générer une table des matières automatique.

2.2 Appliquer et modifier des styles

Appliquer un style est simple. Le modifier pour qu'il corresponde à votre charte graphique est tout aussi important.

Appliquer un style

  1. Sélectionnez le texte (ou placez le curseur dedans).
  2. Onglet Accueil → groupe Styles.
  3. Cliquez sur le style souhaité.

Vous pouvez aussi utiliser les raccourcis :

  • Ctrl+Alt+1 = Titre 1
  • Ctrl+Alt+2 = Titre 2
  • Ctrl+Alt+3 = Titre 3

Modifier un style

  1. Clic droit sur le style dans la galerie.
  2. Choisissez Modifier.
  3. Dans la boîte de dialogue, changez : police, taille, couleur, alignement, interligne...
  4. Cliquez sur Format (en bas) pour plus d'options.
  5. Validez par OK.

Tous les textes utilisant ce style seront immédiatement mis à jour.

Créer votre propre style : Mettez un paragraphe en forme exactement comme vous le souhaitez. Puis clic droit dessus → Styles → Créer un style. Donnez-lui un nom. Il apparaîtra dans votre galerie.

Module 3 20 minutes

3.1 La table des matières automatique

Une table des matières (ou sommaire) liste les titres de votre document avec leurs numéros de page. Word peut la générer automatiquement, à condition d'avoir utilisé les styles Titre 1, Titre 2, Titre 3.

Prérequis indispensable

Avant de créer la table des matières, vous devez avoir :

  • Appliqué le style Titre 1 à tous vos titres principaux.
  • Appliqué le style Titre 2 à tous vos sous-titres.
  • Appliqué le style Titre 3 à vos sous-sous-titres (si nécessaire).

Sans les styles, la table des matières restera vide.

Insérer la table des matières

  1. Placez le curseur au début du document (ou sur une page dédiée).
  2. Onglet Références.
  3. Cliquez sur Table des matières.
  4. Choisissez un style automatique (le premier ou le deuxième).

La table des matières apparaît instantanément, avec les titres et les numéros de page.

Mettre à jour la table des matières : Si vous modifiez votre document (ajout de texte, changement de page), la table ne se met pas à jour toute seule. Cliquez sur la table, puis sur Mettre à jour la table → Mettre à jour toute la table.

Module 3

3.2 Personnaliser la table des matières

La table des matières automatique peut être personnalisée pour correspondre exactement à vos besoins.

Options de personnalisation

  • Nombre de niveaux : décidez jusqu'à quel niveau de titre afficher (1, 2, 3...).
  • Afficher les numéros de page : cochez ou décochez.
  • Points de suite : choisissez le style des pointillés entre le titre et le numéro.
  • Format : choisissez parmi plusieurs présentations (classique, formelle, moderne...).

Table des matières personnalisée

  1. Onglet Références → Table des matières.
  2. Cliquez sur Table des matières personnalisée.
  3. Réglez les options selon vos préférences.
  4. Validez par OK.
Navigation rapide : Dans la table des matières générée, maintenez Ctrl et cliquez sur un titre. Word vous emmène directement à cette section du document. La table des matières est aussi un outil de navigation interactive.

Module 4 30 minutes

4.1 Qu'est-ce que le publipostage ?

Le publipostage (ou mailing) est une fonction qui permet de créer un seul document (lettre, email, étiquette) et de le personnaliser automatiquement pour chaque destinataire à partir d'une liste de contacts.

Exemples concrets

  • Envoyer une lettre d'invitation personnalisée à 100 clients.
  • Créer des badges pour les participants d'un événement.
  • Imprimer des enveloppes avec les adresses de vos contacts.
  • Générer des certificats de formation personnalisés.
  • Créer des factures en série pour plusieurs clients.

Les deux éléments nécessaires

Le publipostage repose sur deux fichiers :

1. Le document principal

La lettre type, avec le contenu fixe (texte, logo) et des champs pour les informations variables (nom, adresse...).

2. La source de données

La liste des destinataires : un tableau Excel, une liste de contacts Outlook, ou une base de données.

Module 4

4.2 Les étapes du publipostage

Word propose un assistant de publipostage en 6 étapes, disponible dans l'onglet Publipostage. Suivez-le dans l'ordre pour un résultat parfait.

  1. Sélectionner le type de document : Lettres, messages électroniques, enveloppes, étiquettes, ou répertoire.
  2. Sélectionner les destinataires : Utiliser une liste existante (fichier Excel), les contacts Outlook, ou créer une nouvelle liste.
  3. Insérer des champs de fusion : Placer les champs variables dans le document : « Prénom », « Nom », « Adresse », « Ville »... Ils apparaissent entre chevrons : «Prénom».
  4. Aperçu des résultats : Parcourir les enregistrements pour vérifier que chaque lettre est correctement personnalisée.
  5. Finaliser la fusion : Générer les documents individuels (un par destinataire) ou les envoyer directement par email.

4.3 Créer la source de données (fichier Excel)

La source de données la plus courante est un fichier Excel. Voici comment le préparer correctement pour le publipostage.

Règles pour le fichier Excel

  • Une colonne par information : Prénom, Nom, Adresse, Ville, Téléphone...
  • Une ligne par destinataire.
  • La première ligne doit contenir les en-têtes (ce sont eux qui deviendront les champs de fusion).
  • Pas de lignes vides au milieu du tableau.
  • Enregistrez le fichier Excel avant de l'utiliser.

Exemple de tableau Excel

CivilitePrenomNomVille
MonsieurIssoufOuédraogoOuagadougou
MadameAminataKonéBanfora
MonsieurDavidSanouBobo-Dioulasso

Dans Word, les champs seront : «Civilite», «Prenom», «Nom», «Ville».

Exercice : Créez un fichier Excel avec 10 contacts (Prénom, Nom, Ville, Téléphone). Enregistrez-le. Dans Word, lancez un publipostage et reliez ce fichier comme source de données.

Module 5 15 minutes

5.1 Utiliser les modèles Word

Un modèle est un document préconçu qui sert de point de départ. Il contient déjà la mise en page, les styles, et parfois du texte d'exemple. Word propose des centaines de modèles gratuits.

Où trouver les modèles ?

  1. Ouvrez Word (page d'accueil).
  2. Dans la barre de recherche, tapez un mot-clé : « CV », « Facture », « Lettre », « Rapport »...
  3. Parcourez les résultats.
  4. Cliquez sur un modèle pour le prévisualiser, puis sur Créer pour l'ouvrir.

Vous pouvez aussi aller dans Fichier → Nouveau pour parcourir tous les modèles.

Modèles les plus utiles

  • CV et lettres de motivation
  • Factures et devis
  • Lettres administratives
  • Agendas et plannings
  • Flyers et brochures
  • Cartes de visite
Astuce : Les modèles sont gratuits. Ils vous font gagner des heures de mise en page. Vous ne partez jamais d'une page blanche.

Module 5

5.2 Créer et enregistrer son propre modèle

Si vous utilisez régulièrement le même type de document (facture, rapport, courrier), vous pouvez créer votre propre modèle pour le réutiliser à l'infini.

Créer un modèle

  1. Créez un document Word normal.
  2. Appliquez toute la mise en forme, les styles, le logo, les zones de texte.
  3. Laissez des zones vides ou du texte d'exemple pour les parties à compléter.
  4. Fichier → Enregistrer sous.
  5. Choisissez l'emplacement.
  6. Dans « Type de fichier », sélectionnez Modèle Word (*.dotx).
  7. Nommez-le et cliquez sur Enregistrer.

Utiliser votre modèle

  1. Fichier → Nouveau.
  2. Cliquez sur Personnel (ou Professionnel).
  3. Votre modèle apparaît.
  4. Cliquez dessus pour créer un nouveau document basé sur ce modèle.

Important : Quand vous ouvrez un modèle, Word crée un nouveau document. Le modèle original reste intact. Vous ne risquez pas de l'abîmer.

Exercice : Créez un modèle d'en-tête de lettre pour NTIC SOLUTION. Incluez le logo, l'adresse (Secteur 15, Quartier Tatana, Banfora), le téléphone et l'email. Enregistrez-le en tant que modèle (.dotx).
