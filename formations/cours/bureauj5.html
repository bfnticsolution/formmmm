Module 1 20 minutes

1.1 Trier des données

Trier signifie réorganiser les lignes d'un tableau selon un ordre précis (alphabétique, numérique, chronologique). Excel peut trier sur une ou plusieurs colonnes simultanément.

Trier rapidement

  1. Cliquez sur une cellule de la colonne à trier.
  2. Onglet Données.
  3. Cliquez sur AZ (croissant : A→Z, 1→9, plus ancien→plus récent).
  4. Ou cliquez sur ZA (décroissant).

Tri personnalisé (plusieurs colonnes)

  1. Sélectionnez tout le tableau (Ctrl+A).
  2. Onglet Données → Trier.
  3. Choisissez une première colonne de tri (ex: Ville).
  4. Cliquez sur Ajouter un niveau.
  5. Choisissez une deuxième colonne (ex: Nom).
  6. Validez par OK.
Exemple : Vous avez une liste de clients avec Ville et Nom. Triez d'abord par Ville, puis par Nom. Tous les clients d'une même ville seront regroupés, et classés alphabétiquement dans chaque ville.

1.2 Filtrer des données

Filtrer signifie masquer temporairement les lignes qui ne correspondent pas à un critère. Les données restent dans le tableau, elles sont simplement cachées. Le filtrage est réversible.

Activer le filtre

  1. Sélectionnez une cellule du tableau.
  2. Onglet Données → Filtrer.
  3. Une flèche apparaît sur chaque en-tête de colonne.

Alternative rapide : Ctrl+Shift+L active/désactive le filtre instantanément.

Utiliser le filtre

  1. Cliquez sur la flèche de la colonne à filtrer.
  2. Décochez les valeurs à masquer, ou utilisez la barre de recherche.
  3. Vous pouvez aussi filtrer par condition : « Supérieur à... », « Contient... », « Entre... ».
  4. Validez par OK.

Les lignes filtrées sont masquées. Les numéros de ligne deviennent bleus pour indiquer qu'un filtre est actif.

Pour supprimer le filtre : cliquez sur la flèche → Effacer le filtre de... ou décochez « Sélectionner tout ». Pour retirer complètement les filtres, cliquez à nouveau sur Filtrer dans l'onglet Données.

Module 2 30 minutes

2.1 La fonction RECHERCHEV()

RECHERCHEV() est l'une des fonctions les plus puissantes et les plus utilisées d'Excel. Elle permet de rechercher une valeur dans un tableau et de renvoyer une information correspondante. C'est l'équivalent de chercher un prix dans un catalogue.

À quoi ça sert ?

Imaginez un tableau avec des codes produits et leurs prix. Dans un autre tableau, vous avez juste le code produit. RECHERCHEV() va retrouver automatiquement le prix correspondant.


Code : P002

Table des prix

Prix : 1 500 F

Syntaxe de RECHERCHEV

=RECHERCHEV(
  valeur_cherchée;
  table_matrice;
  no_index_colonne;
  valeur_proche
)
valeur_cherchéeCe que vous cherchez (ex: un code produit).
table_matriceLe tableau où chercher (incluant la colonne résultat).
no_index_colonneLe numéro de la colonne qui contient le résultat (1, 2, 3...).
valeur_procheFAUX = correspondance exacte (recommandé). VRAI = approximative.

2.2 RECHERCHEV() : exemple concret pas à pas

Prenons l'exemple d'un catalogue de produits dans la feuille « Produits », et d'une facture dans la feuille « Facture ». Nous voulons que la facture affiche automatiquement le prix dès qu'on saisit le code produit.

Tableau source : « Produits »

Ce tableau est dans la Feuille2, plage A1:C5.

A : CodeB : DésignationC : Prix
P001Riz parfumé500
P002Sucre en poudre300
P003Huile d'arachide1 200
P004Savon liquide800

Tableau destination : « Facture »

En B2, on saisit le code produit. En C2, la formule RECHERCHEV.

A : QtéB : CodeC : Prix (formule)
10P002=RECHERCHEV(...)
5P004=RECHERCHEV(...)

Formule en C2 :

=RECHERCHEV(B2; Feuil2!A:C; 3; FAUX)

B2 = le code à chercher (P002)
Feuil2!A:C = le tableau source (toute la feuille Produits, colonnes A à C)
3 = la colonne Prix (3ᵉ colonne du tableau A:C)
FAUX = correspondance exacte obligatoire

Points essentiels :
1. La valeur cherchée doit toujours être dans la première colonne du tableau source.
2. Utilisez toujours FAUX en 4ᵉ argument pour éviter les résultats fantaisistes.
3. Si la valeur n'est pas trouvée, Excel affiche #N/A.

Module 3 30 minutes

3.1 Créer un graphique dans Excel

Un graphique permet de visualiser des données chiffrées en un coup d'œil. Excel propose une grande variété de graphiques. La création se fait en quelques clics.

Méthode universelle

  1. Sélectionnez les données à représenter (y compris les en-têtes).
  2. Onglet Insertion.
  3. Dans le groupe Graphiques, choisissez le type souhaité.
  4. Cliquez sur le modèle.
  5. Le graphique apparaît immédiatement.

Raccourci : Alt+F1 crée un graphique instantané sur la même feuille. F11 le crée dans une nouvelle feuille dédiée.

Personnaliser un graphique

Quand vous sélectionnez un graphique, trois boutons apparaissent à sa droite :

+Ajouter des éléments : titre, légende, étiquettes, quadrillage.
PinceauChanger le style et les couleurs du graphique.
EntonnoirFiltrer les données affichées dans le graphique.

Double-cliquez sur un élément du graphique (barre, axe, titre) pour le modifier directement.

Module 3

3.2 Les 3 types de graphiques indispensables

Parmi la quinzaine de types de graphiques proposés par Excel, trois couvrent 90% des besoins professionnels. Voici quand et comment les utiliser.

Histogramme (Barres)

Usage : Comparer des valeurs entre différentes catégories.

Exemples : Ventes par mois, effectifs par service, notes par étudiant.

Jan
Fév
Mar
Avr

Courbe (Ligne)

Usage : Montrer une évolution dans le temps.

Exemples : Chiffre d'affaires sur 12 mois, température, cours d'une action.

L'orientation de la courbe montre la tendance.

Secteur (Camembert)

Usage : Montrer la répartition, les parts d'un tout.

Exemples : Parts de marché, répartition du budget, origine des clients.

Chaque part représente un pourcentage du total.

Règle d'or : Choisissez le type de graphique en fonction de votre message. Comparaison = histogramme. Tendance = courbe. Répartition = secteur.

Module 4 25 minutes

4.1 Qu'est-ce qu'un Tableau Croisé Dynamique ?

Un Tableau Croisé Dynamique (TCD) est l'outil d'analyse le plus puissant d'Excel. Il permet de résumer, regrouper et explorer des milliers de lignes de données en quelques clics, sans écrire une seule formule.

Ce que fait un TCD

  • Calculer des totaux par catégorie automatiquement.
  • Regrouper des données par mois, trimestre, année.
  • Filtrer et explorer les données interactivement.
  • Créer des tableaux de bord synthétiques.
  • Analyser des données sous différents angles en un clic.

Les 4 zones d'un TCD

FiltresFiltrer tout le tableau (ex: une année spécifique).
LignesLes catégories affichées en lignes.
ColonnesLes catégories affichées en colonnes.
ValeursLes données à calculer (somme, moyenne, compte...).
Dynamique : Le TCD est « dynamique » car vous pouvez réorganiser les champs par simple glisser-déposer. Les calculs se mettent à jour instantanément. Si les données sources changent, il suffit de rafraîchir le TCD.

Module 4

4.2 Créer un Tableau Croisé Dynamique

Créer un TCD est très simple. Excel vous guide pas à pas. Le plus important est d'avoir des données bien structurées au départ.

Prérequis : des données propres

  • Une ligne d'en-tête unique (chaque colonne a un titre).
  • Pas de lignes vides au milieu des données.
  • Pas de totaux dans le tableau source.
  • Chaque colonne contient un seul type de donnée.
  • Le tableau doit être continu (pas de colonnes vides entre les données).

Étapes de création

  1. Cliquez sur une cellule du tableau source.
  2. Onglet Insertion → Tableau croisé dynamique.
  3. Excel sélectionne automatiquement tout le tableau. Vérifiez.
  4. Choisissez Nouvelle feuille (recommandé).
  5. Cliquez sur OK.
  6. Une feuille vierge avec le volet Champs de TCD apparaît.
Construire le TCD : Dans le volet de droite, faites glisser les champs :
— Glissez « Ville » dans la zone Lignes.
— Glissez « Montant » dans la zone Valeurs.
Instantanément, Excel affiche le total des ventes par ville. C'est aussi simple que cela.

Module 4

4.3 Exploiter et personnaliser un TCD

Une fois le TCD créé, vous pouvez le manipuler pour explorer vos données sous tous les angles.

Manipulations courantes

Changer le calculClic droit dans Valeurs → Paramètres des champs de valeurs → Choisir SOMME, MOYENNE, NB...
Ajouter un filtreGlissez un champ dans la zone Filtres. Un menu déroulant apparaît au-dessus du TCD.
ActualiserClic droit → Actualiser. À faire chaque fois que les données sources sont modifiées.
Mise en formeOnglet Création (outils de TCD) → Styles de tableau croisé dynamique.

Graphique croisé dynamique

Vous pouvez créer un graphique lié au TCD qui se met à jour automatiquement quand vous modifiez le TCD.

  1. Cliquez dans le TCD.
  2. Onglet Analyse de TCD → Graphique croisé dynamique.
  3. Choisissez le type de graphique.

Le graphique réagit aux filtres du TCD. C'est un outil de tableau de bord interactif.

Exercice : Créez un tableau de ventes (Date, Produit, Ville, Montant, Vendeur) avec 20 lignes. Créez un TCD qui affiche le total des ventes par Ville et par Produit. Ajoutez un filtre sur le Vendeur.
